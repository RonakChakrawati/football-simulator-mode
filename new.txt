# Football Simulator Codebase Documentation

## Overview
This football simulator is a C++ application that simulates football matches between historical teams using statistical modeling. The application features multiple modes including quick matches, simulations, and menu-driven team selection.

## Architecture Overview
The codebase follows a modular structure with clearly separated concerns:

```
main.cpp
  ├── loader.h      (CSV data loading)
  ├── data.h/cpp    (Hardcoded team data)
  ├── models.h      (Core data models: Player, Team, GoalEvent)
  └── match.h/cpp   (Match simulation logic)
```

## Detailed Component Breakdown

### 1. Entry Point: main.cpp
The application starts in `main.cpp` which:
- Initializes random seed with `srand(time(0))`
- Loads team data either from CSV file (`clubs_teams.csv`) via `loadTeams()` or uses hardcoded data
- Presents a menu system with options:
  1. Career Mode (placeholder)
  2. Quick Match (manual team selection)
  3. Simulation (multiple match simulations)
  4. WC 2026 (placeholder)
  5. Exit

### 2. Data Loading System
Two methods for obtaining team data:

#### A. CSV Loader (loader.h)
- Function: `vector<Team> loadTeams(string filename)`
- Reads `clubs_teams.csv` format: 
  `TeamName,PlayerName,Nationality,Role,Position,Age,Shooting,Passing,Dribbling,Pace,Defending,Physical,Goalkeeping`
- Groups consecutive entries with same team name into Team objects
- Returns vector of Team objects

#### B. Hardcoded Data (data.cpp)
- Function: `vector<Team> createTeams()`
- Contains 16 pre-defined historical teams with authentic player lineups:
  * Barcelona (2011), Real Madrid (2017), Manchester United (2008)
  * Chelsea (2005), Liverpool (2020), Manchester City (2023)
  * AC Milan (2004), Juventus (2015), Inter Milan (2010)
  * Bayern Munich (2013), Arsenal (2004), Atletico Madrid (2016)
  * PSG (2020), Dortmund (2013), Leverkusen (2024), Lyon (2006)
- Each team has exactly 11 players with position-specific stats

### 3. Core Data Models (models.h)

#### Player Class
Attributes:
- Basic info: name, nationality, role, position, age
- Skills (0-100 scale): shooting, passing, dribbling, pace, defending, physical, goalkeeping

Key Methods:
- `getAttack()`: `(shooting*4 + dribbling*3 + pace*2 + passing*2 + physical) / 12`
- `getDefense()`: `(defending*4 + physical*3 + pace*2) / 9`
- `getMidfield()`: `(passing*4 + dribbling*3 + defending*2 + physical) / 10`
- `getGoalkeeping()`: returns goalkeeping value directly

#### Team Class
Attributes:
- `name`: team identifier
- `players`: vector of Player objects (exactly 11 for full team)

Key Methods:
- `getTeamAttack()`: average of all players' getAttack() values
- `getTeamDefense()`: average of all players' getDefense() values
- `getTeamMidfield()`: average of all players' getMidfield() values
- `getTeamGoalkeeping()`: finds and returns GK player's goalkeeping value
- `displayTeam()`: prints detailed team stats to console

#### GoalEvent Class
Simple tracking class for goal events:
- `time`: minute when goal occurred (1-90)
- `playerName`: name of goal scorer

### 4. Match Simulation Engine (match.h/cpp)

#### Match Class
Attributes:
- `homeGoals`: goals scored by first team
- `awayGoals`: goals scored by second team
- `winner`: 0=draw, 1=team1 wins, 2=team2 wins

Primary Method: `score(const Team& t1, const Team& t2)`

#### Simulation Flow Explained

**Step 1: Initialization**
```cpp
homeGoals = 0;
awayGoals = 0;
winner = 0;
vector<GoalEvent> events;
```

**Step 2: Calculate Team Advantages**
```cpp
// Team 1 advantage vs Team 2 defense
int adv = (t1.getTeamAttack() * 3 + t1.getTeamMidfield() * 2) 
          - (t2.getTeamDefense() * 2 + t2.getTeamMidfield() / 2);

// Team 2 advantage vs Team 1 defense  
int dis = (t2.getTeamAttack() * 3 + t2.getTeamMidfield() * 2) 
          - (t1.getTeamDefense() * 2 + t1.getTeamMidfield() / 2);

// Ensure non-negative values
if (adv < 0) adv = 0;
if (dis < 0) dis = 0;
```

**Step 3: Determine Number of Chances**
```cpp
// Base chances + random variation (0-2 extra)
int chances1 = (adv / 18) + 1 + (rand() % 3);
int chances2 = (dis / 18) + 1 + (rand() % 3);
```
*Higher advantage = more scoring opportunities*

**Step 4: Simulate Team 1 Attacks** (loop chances1 times)
For each chance:
1. **Select Attacker**: 
   - Sum attack ratings of forwards (positions 8-10: RW, ST, LW)
   - Weighted random selection based on attack values
   
2. **Select Defender**:
   - Sum defense ratings of defenders (positions 1-3: RB, CB, LB) 
   - Weighted random selection based on defense values
   
3. **Calculate Scoring Probability**:
   ```cpp
   double scoringChance = (double)attacker1.getAttack() 
                         / (attacker1.getAttack() + defender2.getDefense());
   int roll = rand() % 100;  // 0-99 random value
   if (roll < scoringChance * 35) { /* GOAL! */ }
   ```
   *Higher attacker attack vs lower defender defense = higher chance*
   
4. **Record Goal** (if successful):
   - Create GoalEvent with scorer name and random time (1-90)
   - Increment homeGoals
   - Add to events vector

**Step 5: Simulate Team 2 Attacks** (identical process for away team)

**Step 6: Process Results**
```cpp
// Sort goals by time chronologically
sort(events.begin(), events.end(),
     [](const GoalEvent &a, const GoalEvent &b){ return a.time < b.time; });

// Display goal scorers
for (const GoalEvent &g : events) 
    cout << "  " << g.time << "' " << g.playerName << "\n";

// Determine winner
if (homeGoals > awayGoals) winner = 1;
else if (awayGoals > homeGoals) winner = 2;
else winner = 0;  // draw
```

## Data Flow Simulation Example

Let's trace through a Barcelona vs Real Madrid quick match:

1. **User Selection**: 
   - User chooses option 2 (Quick Match)
   - Selects team 1 = Barcelona (index 0)
   - Selects team 2 = Real Madrid (index 1)

2. **Team Object Creation**:
   - `Team a = teams[0];` // Barcelona 2011 squad
   - `Team b = teams[1];` // Real Madrid 2017 squad

3. **Match Initialization**:
   - `Match q1;` creates Match object
   - `q1.score(a, b);` initiates simulation

4. **Inside Match::score()**:
   - Calculates Barcelona's attacking advantage vs Real's defense
   - Calculates Real's attacking advantage vs Barcelona's defense
   - Determines number of chances for each team based on advantages
   - For each chance:
     * Selects Barcelona attacker (weighted by Messi, Villa, Pedro attack stats)
     * Selects Real defender (weighted by Ramos, Varane, Carvajal defense stats)
     * Computes goal probability
     * Records goal if random roll succeeds
   - Repeats for Real Madrid attacks

5. **Result Presentation**:
   - Sorts all goals by time
   - Displays goal scorers with timing
   - Shows final score
   - Declares winner or draw

## Randomness and Variability Sources

1. **Team Selection**: User choice (quick match) or random (simulation mode)
2. **Chance Generation**: `(rand() % 3)` adds 0-2 extra chances
3. **Player Selection**: Weighted random based on skill ratings
4. **Goal Determination**: `rand() % 100` vs scoring threshold
5. **Goal Timing**: `rand() % 90 + 1` (minutes 1-90)

## Statistical Modeling Approach

The simulator uses a simplified but effective model:

- **Team Strength**: Composite of attack/defense/midfield/goalkkeeping averages
- **Match Advantage**: Offensive strength vs defensive strength comparison
- **Scoring Opportunity**: Direct relationship between attacker skill and defender skill
- **Probability Scaling**: Attack/(Attack+Defense) creates realistic 0-1 probability range
- **Goal Frequency**: Scaling factor (*35) tunes goal frequency to realistic levels

## Extensibility Points

1. **Adding New Teams**: 
   - Option A: Add to `clubs_teams.csv` and use loader
   - Option B: Add to `createTeams()` in data.cpp

2. **Modifying Simulation Logic**:
   - Adjust advantage calculation weights in match.cpp
   - Change chance generation formula
   - Modify goal probability calculation

3. **Additional Features**:
   - Career mode implementation (menu option 1)
   - WC 2026 mode (menu option 4)
   - Player injuries, substitutions, formations
   - More detailed match statistics (possession, shots on target, etc.)

## Conclusion

This codebase provides a solid foundation for football match simulation by combining:
- Object-oriented design (Player, Team, Match, GoalEvent classes)
- Data-driven team definitions (CSV or hardcoded)
- Statistically-grounded simulation engine
- Clear separation of concerns
- Extensible architecture for future enhancements

The simulation balances realism with computational efficiency, using weighted probabilities based on player and team statistics to generate varied, believable match outcomes.
